COMPLETE DEFENSE SUITE

Multi-Layered Phishing Vector Interception

Phishing Detector Pro protects against all 6 major web social engineering attack vectors directly inside the browser sandbox.

🎯

Levenshtein Edit Distance Engine

Dynamically compares domain hostnames against 50+ enterprise global brands to flag 1-edit typosquatting (e.g., paypa1.com vs paypal.com).

🎲

Shannon Entropy & DGA Detection

Calculates mathematical information disorder to identify Algorithmically Generated Domains (DGA) used by botnets and C2 servers.

🔤

IDN Homoglyph & Punycode De-Obfuscator

Unmasks Cyrillic/Greek Unicode lookalike characters (Cyrillic 'а' U+0430) and xn-- punycode strings before deceptive links render.

🖼️

Quishing (QR Code Phishing) Inspector

Safely decodes QR code images inside the browser sandbox to inspect destination threat scores without exposing mobile devices.

🔐

In-Page Credential Guard

Prevents password harvesting by alerting users when typing credentials on unencrypted HTTP pages, fake OAuth windows, or cross-domain webhook forms.

📧

Social Engineering Text NLP

Scans raw email text and SMS messages for artificial urgency, coercion, fake account suspension threats, and seed phrase harvesting demands.
